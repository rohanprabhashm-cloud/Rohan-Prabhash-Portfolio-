ROHAN PRABHASH - PROJECT SCREENSHOTS DIRECTORY
===============================================

Place your real project screenshots and UI covers here!

Examples:
- public/projects/oyee.jpg         -> Set imageUrl: "/projects/oyee.jpg" in src/data/initialData.ts
- public/projects/oye-assistant.jpg -> Set imageUrl: "/projects/oye-assistant.jpg"
- public/projects/roam-agent.jpg   -> Set imageUrl: "/projects/roam-agent.jpg"

You can also update project images in the browser:
Click "View Project" on any card -> Click "Edit Project & Image" -> Enter your image path or URL.
